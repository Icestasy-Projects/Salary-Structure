How to get your Zoho credentials:

Step 1: Go to api-console.zoho.in (or .com for US)
Step 2: Create a "Self Client" application
Step 3: Go to "Generate Code" tab
Step 4: Enter scope: ZohoMail.messages.CREATE
Step 5: Generate the code, then exchange it for an Access Token

Get your Account ID:
Open mail.zoho.in/api/accounts while logged into Zoho Mail and copy the accountId from the response.

Note: Access tokens expire (typically 1 hour). When emails fail with "token expired", generate a new token and update it here. For long-term use, set up a refresh token flow.
